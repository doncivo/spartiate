# SPA-001 — Nettoyage du fork : Spartiate démarre vide

Itération : I0 | Taille : **L** (découpée en deux PR : 001a S/M, 001b L) | Budget tokens : 001a ≤ 120 k · 001b ≤ 400 k
Dépend de : SPA-000 (PR #1 fusionnée, `tests.yml` vert sur `main` intact)
Branche : `spa-001a-renommage` puis `spa-001b-purge` (une PR chacune, base `main`, jamais de push direct sur `main`)

## Objectif

Transformer la copie de CircleTasks en une application **Spartiate** vide qui démarre sur PC, avec l'infrastructure intacte (Tauri, SQLite, synchro iCloud, CI, SideStore, plugins repris, agents) et **zéro métier CircleTasks**. À la fin : une fenêtre « Spartiate » avec la coquille (barre latérale 5 sections vides + Plus), l'écran Appareils et synchro fonctionnel, l'écran À propos avec version et date d'expiration de signature.

## Hors périmètre

- Aucun écran ni moteur Spartiate (SPA-009 pour les coquilles, I1 pour le métier).
- Pas de nouveau plugin Swift (SPA-006 / SPA-007).
- Pas de build iOS ni Windows publié (SPA-002 / SPA-003) ; la clé minisign de l'updater et `RELEASES_TOKEN` sont traités en SPA-002.
- Pas de modification de `src/sync/**`, `src-tauri/src/sync/**` ni des tables `sync_*` hors ce que dit 001b § Migration (agent `sync-guardian` obligatoire pour toute autre ligne).
- Pas de traduction EN (Q-5 : FR seul, infrastructure i18n conservée).

## Références

PRD v6.1 : § 3.2–3.4 (repris / supprimé / ajouté), § 19.1 (plugins), § 20 (schéma — **correction : les migrations CircleTasks sont en TypeScript dans `src/db/migrations/0001…0019` et non dans `src-tauri/migrations/` ; le PRD sera corrigé en v6.2**), § 21.1 (emplacements), § 22, § 24 (contrat), § 25.2. ADR CircleTasks 0001 (couches), 0010 (persistance), 0011 (synchro), 0013 (iPhone). Décisions D-7, D-8, D-15, D-18. Hypothèses : H-16 (pas touchée ici), H-18 (outil des tests de migration : **à constater** dans `src/db/migrations/*.test.ts` et le reporter dans `docs/capability-matrix.md`).

# SPA-001a — Renommage et marque (PR 1)

## Critères d'acceptation

1. **Given** le dépôt après 001a, **when** `grep -rn "fr.circletasks.planner" --exclude-dir=node_modules --exclude-dir=.git .`, **then** zéro occurrence hors `docs/adr/`, `docs/journal.md`, `docs/reprise-historique-2026-10.md`, `docs/licences.md`.
2. **Given** `tauri.conf.json`, **then** `productName = "Spartiate"`, `identifier = "fr.spartiate.app"`, updater `endpoints = ["https://github.com/doncivo/spartiate-releases/releases/latest/download/latest.json"]`, `pubkey` **vide avec un commentaire `TODO SPA-002`** dans `docs/decisions.md` (la clé CircleTasks ne doit pas rester : un `latest.json` signé par CircleTasks serait accepté).
3. **Given** `package.json`, **then** name `spartiate`, version `0.1.0`, description FR.
4. **Given** `scripts/ios/plist-contract.json`, `scripts/ios/source.template.json`, `scripts/ios/*.mjs`, `build-ios.yml`, **then** bundle id, nom d'app, dépôt `doncivo/spartiate-releases`, `iconURL` et tag `ios-v*` pointent Spartiate ; les tests `scripts/ios/*.test.ts` sont mis à jour et verts.
5. **Given** `src-tauri/windows/hooks.nsh`, `tauri.smoke.conf.json`, `tests/smoke/*`, `tests/nsis/*`, **then** nom d'installeur, dossier `%APPDATA%\fr.spartiate.app`, raccourcis et désinstallation nomment Spartiate ; les tests NSIS verts (si exécutables sous Windows local, sinon marqués à vérifier en CI).
6. **Given** `src-tauri/src/vault.rs`, `vault_ios.rs`, `sync/service.rs`, **then** le service du coffre et le nom du dossier iCloud deviennent `fr.spartiate.app` / `Spartiate` **sans changer la logique** ; les tests Rust desktop (`restore_*`, `window`, `config`, `export_ios`, `sync_key`) ajustés et verts (`cargo test`).
7. **Given** l'app lancée (`npm run tauri dev` sur PC), **then** titre de fenêtre « Spartiate », icônes `src-tauri/icons/*` régénérées depuis `content/brand/spartiate.svg` (bouclier bronze, Λ rouge, § 18.4) via `npx tauri icon`, aucune icône CircleTasks restante.
8. **Given** `CLAUDE.md`, `AGENTS.md`, `README.md`, `.claude/agents/*.md`, **then** contenu de l'annexe A du PRD (CLAUDE.md complet ; AGENTS.md adapté : chemins `%APPDATA%\fr.spartiate.app`, `iCloud Drive/Spartiate`, dépôts `spartiate*`), agents renommés selon § 24.1 ; aucune mention de CircleTasks sauf « fork de CircleTasks » dans le README et les ADR.
9. `typecheck`, `lint`, `test` (Vitest) verts ; `tests.yml` vert sur la PR.
