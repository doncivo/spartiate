Relecture seule du commit `c8bdb308a3799e5404751c80802ae74b9a9d92c7`, après lecture intégrale du PRD v6.1, puis de SPA-001, du README des maquettes et du dépôt. Gravité : **bloquant** = prescription impossible, démarrage ou intégrité menacés ; **important** = périmètre, preuve ou comportement à corriger ; **mineur** = précision documentaire. Un écart d'identité attendu avant le fork n'est pas en lui-même un défaut : les constats ciblent les affirmations d'héritage et les oublis du plan.
