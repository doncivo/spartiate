Pour le mot de passe et le jeton, utiliser la fonction ci-dessous : Read-Host masque la saisie, la valeur transite seulement en mémoire vers stdin de gh, pas dans ses arguments ni dans l’historique. Exécuter les blocs sans traçage PowerShell. L’encodage UTF-8 conserve un éventuel mot de passe non ASCII. [Contrat gh secret set](https://cli.github.com/manual/gh_secret_set).

```powershell
$spartiateOldOutputEncoding = $OutputEncoding
$OutputEncoding = New-Object System.Text.UTF8Encoding($false)
try {
    Get-Content -LiteralPath $spartiateKeyPath -Raw -Encoding UTF8 |
        gh secret set TAURI_SIGNING_PRIVATE_KEY --repo doncivo/spartiate --app actions
    if ($LASTEXITCODE -ne 0) { throw 'Enregistrement de la clé privée échoué.' }
} finally {
    $OutputEncoding = $spartiateOldOutputEncoding
}

function Set-SpartiateMaskedSecret {
    param([string]$Name, [string]$Environment)
    $secretArgs = @('secret', 'set', $Name, '--repo', 'doncivo/spartiate', '--app', 'actions')
    if ($Environment) { $secretArgs += @('--env', $Environment) }
    $masked = Read-Host "Valeur de $Name (saisie masquée)" -AsSecureString
    if ($masked.Length -eq 0) { $masked.Dispose(); throw 'Valeur vide refusée.' }
    $buffer = [IntPtr]::Zero
    $savedEncoding = $OutputEncoding
    try {
        $OutputEncoding = New-Object System.Text.UTF8Encoding($false)
        $buffer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($masked)
        [Runtime.InteropServices.Marshal]::PtrToStringBSTR($buffer) | & gh @secretArgs
        if ($LASTEXITCODE -ne 0) { throw 'Enregistrement du secret échoué.' }
    } finally {
        if ($buffer -ne [IntPtr]::Zero) {
            [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($buffer)
        }
        $masked.Dispose()
        $OutputEncoding = $savedEncoding
    }
}
Set-SpartiateMaskedSecret -Name TAURI_SIGNING_PRIVATE_KEY_PASSWORD
Set-SpartiateMaskedSecret -Name RELEASES_TOKEN -Environment releases
```

Saisir pour TAURI_SIGNING_PRIVATE_KEY_PASSWORD **le même mot de passe** qu’à la génération ; pour RELEASES_TOKEN, le jeton de l’étape 4. La conversion nécessaire à stdin crée brièvement une chaîne en mémoire ; ne pas la stocker ni l’afficher. Après collage du jeton, vider le presse-papiers avec `Set-Clipboard -Value ''` et fermer la console à la fin. Aucune commande ne contient une valeur privée littérale.
