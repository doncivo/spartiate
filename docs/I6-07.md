## Passe 1 — product-owner

Références : PRD § 14.1 (champ `media`, licence et source obligatoires), § 26.2 (H-9), D-71 (4) (aucune image sans licence vérifiée, repli sans image),
CLAUDE.md (bundle de départ, à la demande dès la création).

Périmètre : un média par exercice du catalogue embarqué (196 exercices, compte de `content/exercises/exercises.json`), fichier local embarqué,
affiché dans la fiche d'exercice de la bibliothèque, attribution visible sous le média. Hors périmètre : vidéo, séance active (D-236), exercices
personnalisés (aucun média), tout téléchargement par l'app, toute modification de la CSP, toute migration.

Critères (Given / When / Then) :

1. **Étant donné** une source candidate, **quand** sa licence n'est pas vérifiée sur la page source (licence, auteur, provenance), ou est NC / ND
   ou floue, **alors** aucun de ses fichiers n'est téléchargé ni embarqué.
2. **Étant donné** un média embarqué, **quand** `validate-content.mjs` tourne, **alors** il échoue si la licence n'est pas dans la liste blanche,
   si la source est inconnue, si le fichier manque, n'est pas au registre de provenance (empreinte SHA-256, taille, chemin d'origine), dépasse
   153 600 octets, si le total dépasse 8 388 608 octets, si un exercice a plus d'un média, si un fichier est orphelin ou dans un format non
   admis, ou si une adresse réseau apparaît dans le contenu média.
3. **Étant donné** un exercice avec média, **quand** Ali ouvre sa fiche, **alors** l'image s'affiche avec un texte alternatif et, dessous,
   l'attribution (auteur, licence, adresse de la licence) ; **étant donné** un exercice sans média ou une image illisible, **alors** aucune
   icône cassée : rien (sans média) ou « Illustration indisponible » (erreur de chargement, visible).
4. **Étant donné** le build, **quand** la garde du bundle tourne, **alors** le composant média et ses textes sont un bloc à la demande, hors du
   départ ; aucune image du catalogue n'est référencée par un bloc de départ ; le départ reste ≤ 358 400 octets gzip ; `start-modules.json`
   ne grandit pas.
5. **Étant donné** le code de chargement, **quand** le test de garde le lit, **alors** il ne contient aucune adresse `http(s)://` ; la CSP
   (`img-src 'self' data: asset: http://asset.localhost`) est inchangée.
