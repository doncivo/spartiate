# Questions à décider par Ali

les documents actifs de `docs/`. Les échéances sont le dernier moment utile
avant de figer les contrats correspondants. Les recommandations ne remplacent
pas une décision d’Ali.

Les occurrences de `docs/archive/circletasks/` sont conservées dans le même
tableau pour exhaustivité, mais sont historiques, en lecture seule et hors du
périmètre du PRD Spartiate ; elles ne constituent pas des questions produit
actives.
