# Spartiate

App personnelle d'entraînement, nutrition et récupération, pour un seul utilisateur : PC Windows et iPhone, un même code (Tauri 2, React, TypeScript, SQLite).
Spartiate est un fork de CircleTasks : l'infrastructure (synchro iCloud chiffrée, sauvegardes, journaux, chaîne de build et de mise à jour) en est reprise ; le métier est neuf.
